# Statistics
## Overview<a name="ZH-CN_TOPIC_0000002470925200"></a>

3A statistical information and related configurations provided by ISP.

## Function Description<a name="ZH-CN_TOPIC_0000002504084979"></a>

### AE Statistics<a name="ZH-CN_TOPIC_0000002503965131"></a>

Implements the statistics for auto exposure information. The software adjusts the sensor based on the statistical information to achieve auto exposure functionality. AE statistics include zone-based R/Gr/Gb/B mean statistics, weighted global R/Gr/Gb/B means, and 1024-bin histogram information.

#### AE Zone Statistics<a name="ZH-CN_TOPIC_0000002503964865"></a>

AE supports a maximum of 17x15 blocks and a minimum of 1x1 block. Each block can output 16-bit R, Gr, Gb, B mean values (Average R/Gr/Gb/B). Taking R and Gr as examples, the correspondence between block statistics read addresses and data is shown in [Table 1](#_Ref430175021). m represents the number of horizontal zones, n represents the number of vertical zones.

#### AE Histogram Statistics<a name="ZH-CN_TOPIC_0000002470924922"></a>

AE provides 1024-bin histogram statistics. The bit width of each histogram bin is 25 bits. The histogram range is [0, 1023] in 10-bit precision.

#### AWB Statistics<a name="ZH-CN_TOPIC_0000002471084872"></a>

Implements statistics for auto white balance information. The software adjusts the white balance gain based on the statistical information to achieve auto white balance functionality.

#### AF Statistics<a name="ZH-CN_TOPIC_0000002470925104"></a>

Implements statistics for auto focus information, providing high-frequency information of the image windows for focus evaluation.
