# Boards

The Hi3403 platform currently supports the following Hi3403V100 development boards. Click to view each board
**Hardware features, pin diagrams, schematics, official information, image downloads**, etc.

<div class="grid cards" markdown>

-   :material-developer-board:{ .lg .middle } __Topeet iTOP-Hi3403__

    ---

Manufactured by Topeet (迅为). The official SDK reference board — richest peripherals and most complete documentation. Recommended for beginners.

    [:octicons-arrow-right-24: Enter](topeet/index.md)

-   :material-developer-board:{ .lg .middle } __LubanCat-Hi3403 (Wildfire)__

    ---

Manufactured by Wildfire (野火). Ships with pre-installed Buildroot and an active community ecosystem.

    [:octicons-arrow-right-24: Enter](lubancat/index.md)

-   :material-developer-board:{ .lg .middle } __Euler Pi__

    ---

    Manufactured by Ebina (易百纳). Optimized for OpenEuler.

    [:octicons-arrow-right-24: Enter](ebaina/index.md)

-   :material-developer-board:{ .lg .middle } __runkaihong (rkh)__

    ---

    OpenHarmony desktop system optimization, suitable for OpenHarmony development.

    [:octicons-arrow-right-24: Enter](rkh/index.md)

-   :material-developer-board:{ .lg .middle } __Zhongshan Kuangshi (中山狂石)__

    ---

    Contains a complete demo (AI examples such as face_detection, kcf_track, fruit_identify, etc.).

    [:octicons-arrow-right-24: Enter](zsks/index.md)

</div>
